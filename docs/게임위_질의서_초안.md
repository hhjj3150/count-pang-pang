## 1. 서비스 개요

- 서비스 이름: 카운터 팡팡
- 형태: 웹 앱(휴대폰 브라우저·홈 화면 추가). 추후 구글 플레이스토어 출시 예정
- 주소: [https://count-pang-pang.vercel.app]
- 대상: 초등학생부터 어른까지 (만 14세 미만 이용자 포함)
- 내용: 번호판 숫자로 덧셈·뺄셈·크기 비교·수 가르기 등을 푸는 연산 학습 게임 (레벨 0~14, 한 판 15문제, 제한 시간 있음)
- 게임 요소: 정답 포인트, 레벨 통과, 띠 승급(누적 포인트), 꾸미기 아이템(카트·배경·이모티콘), 월간 랭킹
- 수익 방식(예정): 광고, 월 유료 회원(이용권)
- 확률형 아이템, 유료 재화로 하는 뽑기, 이용자 간 거래 기능은 없습니다.
- 등급분류: [아직 받지 않음 / 신청 예정]

## 2. 재화 구조

| 구분 | 얻는 방법 | 쓰는 곳 | 현금 전환 |
|---|---|---|---|
| 포인트(P) | 문제 정답, 레벨 통과, 출석 등 **게임 이용 결과** | 게임 안 아이템, 띠 승급, 랭킹 | 없음 (돈으로 살 수도, 바꿀 수도 없음) |
| 캐시(C) **(계획, 현재 미제공)** | **게임 결과와 관계없는 활동**: 보상형 광고를 끝까지 시청(1회 2C), 초대 링크로 친구가 가입(1명 5C) | 모바일 상품권(기프티콘, 1,000원~20,000원 상당) 교환, 월 1회 | 아래 질의 대상 |

- 캐시는 게임 결과(점수, 통과, 순위)로는 얻을 수 없도록 설계했습니다.
- 캐시는 돈으로 살 수 없고, 다른 이용자에게 넘길 수 없으며, 포인트와 서로 바꿀 수 없습니다.
- 캐시는 계정을 연결한 이용자에게만 서버에서 적립하며, 만 14세 미만은 보호자 동의(본인인증) 후에만 교환할 수 있도록 할 계획입니다.
- 현재는 판단을 받기 전까지 캐시·상품권 기능을 화면에서 숨겨 두었습니다.

## 3. 질의 사항

1. 위 서비스가 「게임산업진흥에 관한 법률」상 **게임물**에 해당하는지, 해당한다면 제21조의 **교육·학습 용도 게임물**(등급분류 면제)로 볼 여지가 있는지 궁금합니다.

2. 게임 결과와 관계없는 활동(광고 시청 완료, 친구 초대 가입)으로 적립한 캐시를 **모바일 상품권으로 교환**해 주는 것이 제28조 제3호의 **경품 제공**에 해당하는지 궁금합니다.

3. 2번이 경품 제공에 해당한다면, 허용될 수 있는 방식이 있는지 궁금합니다. 예를 들면 다음과 같습니다.
   - 기간을 정한 홍보 이벤트로만 운영하는 경우
   - 금액이나 횟수에 한도를 두는 경우
   - 상품권 교환 기능을 게임과 분리된 별도 서비스(앱)로 운영하는 경우

4. 매일 출석, 게임 참여(예: 하루 5판 플레이) 같은 **"오늘의 미션"을 완료한 보상**으로 캐시를 주는 경우, 2번과 판단이 달라지는지 궁금합니다.

5. 게임 결과로 얻은 **포인트를 한 달에 한 번, 일정량(예: 50,000P)을 모으면 캐시로 바꿔 주는 것**이 제28조 제3호(경품)나 제32조 제1항 제7호(환전)에 해당하는지 궁금합니다. (현재 계획에는 넣지 않았으며, 참고로 여쭙니다.)
